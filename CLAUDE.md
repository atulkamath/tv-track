# tv-track

A personal TV-watching tracker: log shows via natural language, accrue Watch Time, compare with friends on a Leaderboard. See `CONTEXT.md` for the domain glossary and `docs/mvp-scope.md` for the agreed MVP scope and API surface.

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (atulkamath/tv-track), via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-label vocabulary (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
